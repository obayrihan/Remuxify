PRECISION OVER GUESSWORK

Detection rules.

Only your enabled rules mark a file as a compatibility candidate.

AUTO QUEUE OFF
The initial compatibility rule matches MP4 + HEVC Main 10 + yuv420p10le + hev1. The default conversion uses 8-bit HEVC Main + hvc1. A rule match is a compatibility candidate, not a universal HEVC defect.

Edit matching rules

ALL CONDITIONS MUST MATCH

Values in one list are alternatives. Separate rules are alternatives. Empty rules are rejected. Supported fields: video_codecs, profiles, pixel_formats, containers, codec_tags, min_bit_depth, max_bit_depth, min_width, interlaced.

Editing rules never starts a conversion by itself.
ENCODER & SAFETY LIMITS

Make it your own.

Changes apply to newly queued jobs. Existing jobs keep their selected preset.

Output preset

NVIDIA H.265

NVDEC accelerates source decoding and bit-depth conversion on supported files. Final validation still decodes every video/audio frame independently on the CPU. HDR / Dolby Vision, interlaced content, and unsupported stream layouts are blocked pending a dedicated profile. MP4 converts text subtitles to timed text; use MKV to retain their original format and attachments. Re-encoding is lossy.

Resource guardrails

CHECKED BEFORE & DURING JOBS

Storage preflight reserves a conservative maximum output estimate plus the free disk reserve. RAM, VRAM, and disk space are checked during a job. Resource interruptions restart the encode from the original once it is safe. Playback never interrupts an active encode or validation.

Queue behavior

Interrupted jobs survive a reboot. Failed encodes never replace the original.

qBittorrent file protection

NOT CONNECTED

Stop only completed torrents containing the exact source file before conversion and replacement. Other torrents keep running. Matching torrents stay stopped after success or failure; converted files no longer match the torrent hashes. Incomplete downloads wait.

Connection uses 127.0.0.1 only. Saving tests login without stopping any torrent.
